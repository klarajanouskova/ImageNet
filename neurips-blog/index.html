ReImageNet: The ImageNet‑1k Validation Set, Done Right

50,000 images reannotated from scratch — multilabel, localized, with semantic attributes and revised class definitions.

~13% of original labels are incorrect
32.7% of images are multi-label vs. 14.9–21.6% in prior work
4.7% contain no valid ImageNet‑1k object at all
100k localized bounding boxes
Abstract

Overview

ReImageNet is a from-scratch reannotation of all 50,000 images of the ImageNet‑1k validation set, unifying multilabel correction, per-instance bounding-box localization, revised class definitions, and five semantic attributes — rendition, reflection, text-recognition, crowd, and dominant. The reannotation reveals that ≈13% of original labels are incorrect, 32.7% of images are multilabel (vs. 14.9–21.6% in prior work), and 4.7% contain no valid ImageNet‑1k class. With corrected labels, top-1 accuracy rises 0.7–1.4% for supervised models and 6–8% for MLLMs. Annotation errors propagate into derivative benchmarks at 1.3–4.4× the original rate. All annotations and class definitions are publicly released; evaluation code will be released soon.

Dataset

The ReImageNet Dataset

Multilabel JSON (50k images) ~96k bounding boxes 5 attribute flags per box Revised class definitions (1,000 classes) Evaluation code (coming soon)

Every immediately visible object belonging to one of the 1,000 classes is annotated with a bounding box, label, and optional semantic attributes. Annotators follow a structured per-class preparation protocol — studying images, revising class definitions, resolving ambiguities — before any image-level labeling begins.

Evaluation Protocol

All results use ReaL accuracy (Beyer et al., 2020) as the scoring function: a prediction is correct if it matches any ground-truth label for the image. For the 13 pairs of semantically duplicate ImageNet‑1k classes, either class in the pair is accepted as correct — this is applied to both corrected and original labels to ensure a fair comparison. The 4.7% of images that carry no valid ImageNet‑1k label are scored as automatically correct, keeping the denominator at the full 50,000 images and preserving backward compatibility with standard ImageNet‑1k benchmarks.

MLLMs Score 6–8% Higher With Corrected Labels and Proper Evaluation Protocol

If you've been reporting ImageNet‑1k accuracy for an MLLM, its score is understated. Supervised models also benefit, but far less. On the hard subsets S⁻ (single-label images where the original label is wrong) and M⁻ (multilabel images where the original label is absent), MLLMs score 39–43% — well ahead of VLMs (35–39%) and supervised models (29–33%). Language-vision training gives MLLMs a clear edge on genuinely ambiguous images that pure supervised models struggle with.

Accuracy by Semantic Attribute

Rendition degrades all models (−0.2% to −7.4%). Text-recognition shows the sharpest split: language-aligned models gain +7–17% by leveraging visible text, while pure supervised models suffer (EffNetV2: −4.9%). Crowd universally improves accuracy (+1–4%). Reflection generally helps (+0.3–4.0%), with GPT-5.4 and Gemma 4 as outliers (both negative).

Evaluation

Object-Centric Evaluation Protocols

ReImageNet's bounding boxes unlock object-centric evaluation. Removing scene context reveals a stark gap: supervised models lose up to 33% accuracy on tight crops, while MLLMs are substantially more robust — reflecting their diverse training data. ExCrops recover ~10% over tight crops while remaining backward-compatible with single-label evaluation.

Benchmarks

Errors Don't Stay in ImageNet

Label noise in ImageNet‑1k propagates directly into derivative test sets, amplified at 1.3–4.4× the original rate. If you evaluate on ImageNet-A, -R, or -Sketch, you're working with up to 15% mislabeled images. Any benchmark built on the ImageNet‑1k taxonomy inherits its annotation flaws by construction.

Annotation Methodology

The Quality Ceiling for Large-Scale Annotation

ReImageNet was produced by 7 trained in-house annotators following a structured per-class preparation protocol, supported by detector and MLLM predictions as optional reference. Continuous communication uncovered edge cases throughout, requiring repeated mid-annotation revisions of guidelines, class definitions, and attributes. A case study found that when GPT-4o disagreed with trained annotators, the annotators were wrong approximately 50% of the time — confirming that MLLMs and humans are complementary, and that reliable annotation at this scale is inherently iterative.

Because a single pass cannot catch everything, the current release is accompanied by an active second verification phase: annotators revisit already-annotated images against the now-finalised guidelines, with anonymized MLLM+SAM predictions, first-pass annotations, and original ImageNet labels as optional reference. Only minor refinements are expected and the published results are representative of the final dataset.

We do not claim the annotations are error-free. Residual inter-annotator variance remains: which objects count as immediately visible, where exactly to draw a bounding box, and which instances carry the dominant attribute all involve judgment calls.

We see the benchmark as something that should evolve iteratively over time. All annotations, class definitions, and guidelines are publicly available. If you find an error or a case the guidelines do not cover, we invite you to flag it — community corrections will be tracked and folded into future versioned releases.
